# OCEAN Reliability Error Taxonomy

| Code | Error |
|---|---|
| E01 | Unsupported strong claim |
| E02 | Association upgraded to causality or mechanism |
| E03 | Technical performance upgraded to clinical utility |
| E04 | Citation exists but does not support the linked statement |
| E05 | Abstract-only evidence treated as full-text evidence |
| E06 | Species, tissue, disease, cell, intervention, or outcome mismatch |
| E07 | Circular validation or shared upstream evidence |
| E08 | Patient, sample, site, time, benchmark, or source-record leakage |
| E09 | Missing experimental unit or pseudoreplication |
| E10 | Missing uncertainty, multiplicity control, or effect estimate |
| E11 | Incomplete run provenance or environment lock |
| E12 | No-hit, failure, conflict, or negative evidence dropped |
| E13 | Evidence boundary lost across sessions or revisions |
| E14 | Availability/installation probe misreported as scientific execution |
| E15 | Tool execution misreported as biological validation |
| E16 | Submission, posting, peer review, acceptance, and publication conflated |
| E17 | Audit language leaked into paste-ready manuscript prose |
| E18 | Private data, credentials, or unconfirmed status exposed |

Every benchmark error should retain the source locator, expected decision,
observed decision, severity, reviewer confidence, and adjudication status.
